# Cadastro de Usuários #

Projeto de uma página de cadastro de usuários desenvolvida para praticar conceitos fundamentais de desenvolvimento front-end.

A aplicação possui uma interface simples, clara e responsiva, com validações realizadas utilizando JavaScript.

##  Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

##  Funcionalidades

* Cadastro através de formulário;
* Validação do nome;
* Validação do e-mail;
* Validação do telefone;
* Validação da senha;
* Mensagens de erro para campos inválidos;
* Destaque visual dos campos com erro;
* Mensagem de confirmação após o cadastro;
* Limpeza do formulário após o cadastro.

##  Como executar

### 1. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

### 2. Acesse a pasta

```bash
cd cadastro-usuarios
```

### 3. Abra o projeto

Você pode abrir o arquivo `index.html` diretamente no navegador.

No Windows, também é possível executar pelo terminal:

```bash
start index.html
```

Outra opção é utilizar a extensão **Live Server** no Visual Studio Code.

##  O que foi praticado

Este projeto foi desenvolvido para praticar conceitos importantes de JavaScript, incluindo:

* Seleção de elementos do DOM;
* Eventos;
* `addEventListener`;
* Funções;
* Condicionais;
* Expressões regulares;
* Manipulação de elementos HTML;
* Validação de formulários;
* Manipulação de classes CSS;
* `preventDefault()`;
* Manipulação de valores de inputs.
